# Repositório de Exercícios de ROOT e Masterclass

Este repositório contém a resolução dos exercícios de análise de dados em C++ utilizando a biblioteca CERN ROOT.

## Estrutura do Projeto

* **`exercicio1/`**: Introdução ao ROOT e criação de histogramas simples.
* **`exercicio2/`**: Ajuste de funções (Fitting) e manipulação de árvores básicas.
* **`exercicio3/`**: Manipulação e leitura de vetores e múltiplos eventos.
* **`exercicio4/`**: Leitura do arquivo `tree.root`, cálculo do momento total p = sqrt{p_x^2 + p_y^2 + p_z^2} e aplicação de filtros avançados usando objetos `TCut`.
* **`masterclass/`**: Análise da ntupla NanoAOD do CMS OpenData gerada com `MakeClass` (`MeuAnalise.C` e `MeuAnalise.h`), extraindo distribuições do número de múons, p_T e eta.
